# IT Support & Systems

## 1. Helpdesk
- **Email:** it-support@company.com
- **Phone:** Ext. 5555
- **Portal:** https://helpdesk.company.com
- **Hours:** 8:00 AM – 8:00 PM (Mon–Fri); on-call for P1 incidents.

### Ticket Priority Levels
| Priority | Description                        | Response SLA | Resolution SLA |
|----------|------------------------------------|--------------|----------------|
| P1       | Critical outage / security breach  | 15 min       | 4 hours        |
| P2       | Major functionality impacted       | 1 hour       | 8 hours        |
| P3       | Minor issue / workaround available | 4 hours      | 3 days         |
| P4       | Request / question                 | 1 day        | 5 days         |

## 2. Laptop & Equipment
- Standard issue: company laptop, monitor, keyboard, mouse, headset.
- Replacement requests require manager approval for items over $200.
- Lost or stolen devices must be reported to IT **within 24 hours**.

## 3. Software
- Only approved software from the **Software Catalog** may be installed.
- New software requests go through the IT portal and require a security review.
- Unlicensed software is strictly prohibited.

## 4. Accounts & Passwords
- Passwords must be **at least 12 characters** with mixed case, numbers, and symbols.
- Password rotation: every **90 days**.
- MFA is mandatory for all company accounts.
- Never share credentials. Report suspected compromise immediately.

## 5. VPN & Remote Access
- VPN is required when accessing internal systems outside the office.
- Use the company-provided VPN client only.
- Do not connect to untrusted public Wi-Fi without VPN.

## 6. Backups
- Company data is backed up nightly.
- Personal files must be stored in OneDrive/SharePoint, not local drives.
- Recovery requests: submit a ticket with file paths and dates.

## 7. Network
- Guest Wi-Fi: `Company-Guest` (password from reception).
- Corporate Wi-Fi: `Company-Secure` (domain credentials required).
- Report connectivity issues with the ticket tool including traceroute output.
